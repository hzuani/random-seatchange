# 자리 배치 프로그램

학급 자리 배치를 손쉽게 관리하는 웹 기반 프로그램입니다. 빌드 도구 없이 HTML 파일 하나만 브라우저에서 열면 바로 사용할 수 있습니다.

## 주요 기능

### 명단 관리
- **나이스(NEIS) 엑셀 파일 업로드** — `.xlsx`, `.xls`, `.csv` 형식 지원
  - 나이스 경로: `[학급담임] → [기본학적관리] → [명렬표출력] → [조회] → [엑셀내려받기]`
  - 업로드 시 번호와 이름이 좌석에 함께 표시됨
- 엑셀 없이 **총 학생 수(끝번호)만 입력**해서 번호만으로도 사용 가능
- **제외할 번호** 지정 (예: 전학, 결석 학생)

### 자리 배치
| 기능 | 방법 |
|------|------|
| 번호순 배치 | `번호순 자리 배치` 버튼 클릭 |
| 무작위 섞기 | `무작위 자리 섞기` 버튼 클릭 (섞을 횟수 지정 가능) |
| 두 자리 교환 | 바꿀 두 좌석 순서대로 클릭 |
| 좌석 고정 | 좌석의 `L` 버튼 클릭 (섞기 시 제외됨) |
| 시크릿 고정 | 좌석 **우클릭** (고정 표시 없이 몰래 고정) |

### 저장 / 불러오기
- 현재 배치를 **JSON 파일**로 저장하고 나중에 불러올 수 있음
- 학급명, 학생 수, 제외 번호, 명단, 고정 상태까지 모두 보존

### 인쇄
- **학생 시점** — 일반 방향으로 인쇄 (학생이 보는 방향)
- **교사 시점** — 좌우 반전 + 칠판 아래 배치로 인쇄 (교단에서 보는 방향)

## 사용 방법

1. `자리_배치_프로그램.html` 파일을 브라우저에서 열기
2. (선택) 나이스에서 내려받은 엑셀 명렬표 업로드
3. 학급명, 학생 수, 제외 번호 입력
4. `번호순 자리 배치` 또는 `무작위 자리 섞기` 클릭
5. 필요시 좌석 고정 후 다시 섞기
6. `저장하기`로 현재 상태 보관

## 기술 스택

- **HTML / CSS / JavaScript** (바닐라, 빌드 도구 없음)
- **[Pretendard](https://github.com/orioncactus/pretendard)** — 한국어 최적화 폰트
- **[SheetJS (xlsx)](https://sheetjs.com/)** — 엑셀 파일 파싱

## 호환성

최신 Chrome, Safari, Edge, Firefox에서 동작합니다. 인터넷 연결 시 폰트와 SheetJS CDN을 로드합니다.
